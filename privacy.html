Privacy policy

The llm-wiki gmail archiver is a personal, single-user tool for the owner's own Gmail account.

Read-only access and local storage

The tool uses only the https://www.googleapis.com/auth/gmail.readonly scope for the owner's own account. Gmail data is stored only on the owner's local machine.

Use and disclosure

No Gmail data is sold, shared, transferred, or used for advertising or AI training. No Gmail data is disclosed to third parties.

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revocation and contact

Access can be revoked at Google account permissions. Revoking access stops future authorized collection; existing local archives remain under the owner's control.

For contact, use the source repository's GitHub issues.
